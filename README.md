# 🎓 Student Management System – SQL Project

## 📌 Project Overview
The Student Management System is a beginner-level SQL project developed using MySQL. It helps manage student records, departments, courses, instructors, and student enrollments in a structured database.

## 🎯 Project Objectives
- Store and manage student information.
- Maintain department and course details.
- Manage instructor information.
- Track student course enrollments.
- Retrieve and analyze academic data using SQL queries.

## 🗂️ Database Tables

1. **Students:** Stores student ID, first name, last name, email, birth date, and enrollment date.
2. **Departments:** Stores department ID and department name.
3. **Courses:** Stores course ID, course name, department ID, and credits.
4. **Instructors:** Stores instructor ID, name, email, and department ID.
5. **Enrollments:** Stores enrollment ID, student ID, course ID, and enrollment date.

## 🔗 Database Relationships
- One department can have multiple courses.
- One department can have multiple instructors.
- One student can enroll in multiple courses.
- One course can have multiple students.
- Enrollments connects Students and Courses.
